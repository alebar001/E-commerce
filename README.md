# E-commerce

Interface de e-commerce desenvolvida com **React** e **Redux**, criada como projeto de estudo para praticar o desenvolvimento de aplicações web, organização de componentes e gerenciamento de estado.

## Demonstração

![Demonstração do E-commerce](https://user-images.githubusercontent.com/102175591/165842544-02b23042-db7f-47dc-b1db-18c17c635700.gif)

## Sobre o projeto

O projeto simula uma loja virtual de produtos esportivos, com uma interface inspirada em um catálogo de e-commerce. A aplicação apresenta produtos, categorias e ações de navegação em uma experiência simples e objetiva.

O desenvolvimento fez parte de um desafio front-end da [DIO](https://www.dio.me/), com foco na construção de uma interface utilizando React e Redux.

## Funcionalidades

- Exibição de produtos em formato de catálogo;
- Organização dos itens por categorias;
- Navegação entre as páginas da aplicação;
- Componentização da interface;
- Gerenciamento de estado com Redux;
- Layout visual desenvolvido para simular uma loja virtual;
- Estrutura preparada para evolução de funcionalidades, como carrinho e detalhes dos produtos.

## Tecnologias utilizadas

- [React](https://react.dev/);
- [Redux](https://redux.js.org/);
- [React Router](https://reactrouter.com/);
- [Material-UI](https://mui.com/);
- JavaScript;
- HTML5;
- CSS3.

## Como executar o projeto

### Pré-requisitos

Antes de começar, certifique-se de ter o [Node.js](https://nodejs.org/) e o npm instalados em sua máquina.

### Instalação

Clone este repositório:

```bash
git clone https://github.com/alebar001/E-commerce.git
```

Acesse a pasta do projeto:

```bash
cd E-commerce
```

Instale as dependências:

```bash
npm install
```

Inicie a aplicação em ambiente de desenvolvimento:

```bash
npm start
```

Após a inicialização, acesse [http://localhost:3000](http://localhost:3000) no navegador.

## Scripts disponíveis

| Comando | Descrição |
| --- | --- |
| `npm start` | Inicia o servidor de desenvolvimento. |
| `npm run build` | Gera a versão otimizada para produção. |
| `npm test` | Executa os testes configurados no projeto. |
| `npm run eject` | Copia as configurações do Create React App para o projeto. |
